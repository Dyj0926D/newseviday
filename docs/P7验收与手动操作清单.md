## 4. 第二设备迁移演练

状态：**已延期。** 当前仓库、锁文件、示例配置、migration 与迁移说明已经版本化；实际迁移将在个人设备准备好后执行。

在个人设备执行全新 clone，不复制当前设备的 `node_modules`、`.venv`、`.dev.vars` 或 CLI 登录缓存：

```powershell
git clone https://github.com/Dyj0926D/newseviday.git
cd newseviday
npm ci
python -m pip install --user uv
python -m uv sync --project pipeline --frozen
npm run check
npm run pipeline:check
```

随后重新登录个人 GitHub、Cloudflare 和 EdgeOne 账号。云端 Secret 不需要导出；只验证新设备能看到 Secret 名称和部署配置，不读取 Secret 值。

验收记录：

- [ ] 全新 clone 成功；
- [ ] Node 与 Python 锁文件重建成功；
- [ ] `npm run check` 通过；
- [ ] `npm run pipeline:check` 通过；
- [ ] 本地 archive 模式能浏览页面和快照；
- [ ] 不依赖公司代理、公司账号或内部制品源；
- [ ] 个人远程确认可恢复后，退出当前公司设备上的个人 OAuth/Token。

## 5. 真实 DeepSeek 烟雾测试

该项已转入受控一周试运行准备，不作为 P7 完成条件。详细范围、额度、日程和停止条件见 `docs/AI一周试运行评估.md`。首次付费调用前确认：

- 供应商官方文档中的准确 model ID 已核对为 `deepseek-v4-pro`；
- 2026-08-02 官方缓存未命中输入价 3 元/百万 Token、输出价 6 元/百万 Token，调用前再复核一次；
- `DEEPSEEK_THINKING_ENABLED=false`，使用非思考模式控制延迟和 Token；
- P7 分支已发布且 `/api/status` 显示保护就绪；
- D1 当前预算为 0 或符合预期；
- 只短时开启 `AI_ENABLED`，RAG 质量 Gate 未通过时不开放公共问答；
- 测试结束立即恢复关闭状态并核对 D1 结算。

## 6. 明确延后

- 稳定中国大陆直连：当前实测直连失败、VPN 正常；待自定义域名/备案或替代托管条件成熟后复测；
- 第二设备迁移演练：待个人设备准备好后按第 4 节执行；
- Vectorize 与 BGE-M3 云端实测：继续服从 P6 生产检索 Gate；
- 30 题人工复核、引用覆盖和无答案识别提升：继续服从 P6 质量 Gate；
- 公网运营控制台：不进入 MVP，通过版本化 Wrangler 配置调整额度；
- 永久 EdgeOne 大陆链接：无域名和备案条件下不承诺。
