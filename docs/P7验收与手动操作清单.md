# NewsEviday P7 验收与手动操作清单

## 1. 当前结论

P7 可由代码和云资源自动完成的部分已经完成：D1 持久限额、并发租约、预算预留/结算、Turnstile、幂等键、CSP 与安全状态均已落地。远程 D1 migration 已执行，AI 与 RAG 仍为关闭状态，没有产生 DeepSeek 调用。

以下事项必须由用户在真实设备、真实网络或 Git 发布流程中确认。它们不会阻塞静态网站访问，也不应通过临时打开 AI 来代替。

## 2. 发布 P7 分支

当前开发分支：`codex/p7-guardrails`。

确认自动化检查与 GitHub CI 通过后，再决定是否合并到 `main`。合并会触发已配置的 Cloudflare Git 部署；在此之前，线上主站仍运行旧版本，远程 D1 不承载生产流量。

发布后检查：

```powershell

curl.exe -sS https://newseviday.dyjnewseviday-worker.workers.dev/api/status
curl.exe -sS https://newseviday.dyjnewseviday-worker.workers.dev/api/runtime-config
```

预期：

- `ai.state=static-only`、`rag.state=static-only`；
- `protection.persistentGuardrails=available`、`protection.turnstile=enabled`；
- 页面和历史快照仍可浏览；
- 不调用 DeepSeek。

## 4. 第二设备迁移演练

在个人设备执行全新 clone，不复制当前设备的 `node_modules`、`.venv`、`.dev.vars` 或 CLI 登录缓存：

```powershell
git clone https://github.com/Dyj0926D/newseviday.git
cd newseviday
npm ci
python -m pip install --user uv
python -m uv sync --project pipeline --frozen
npm run check
npm run pipeline:check
```

随后重新登录个人 GitHub、Cloudflare 和 EdgeOne 账号。云端 Secret 不需要导出；只验证新设备能看到 Secret 名称和部署配置，不读取 Secret 值。

验收记录：

- [ ] 全新 clone 成功；
- [ ] Node 与 Python 锁文件重建成功；
- [ ] `npm run check` 通过；
- [ ] `npm run pipeline:check` 通过；
- [ ] 本地 archive 模式能浏览页面和快照；
- [ ] 不依赖公司代理、公司账号或内部制品源；
- [ ] 个人远程确认可恢复后，退出当前公司设备上的个人 OAuth/Token。

## 5. 真实 DeepSeek 烟雾测试

该项不属于本轮自动执行。只有用户再次明确确认后才执行一次最小调用，并在调用前确认：

- 供应商控制台中的准确 model ID；
- 当期输入/输出 Token 单价；
- P7 分支已发布且 `/api/status` 显示保护就绪；
- D1 当前预算为 0 或符合预期；
- 只短时开启 `AI_ENABLED`，RAG 质量 Gate 未通过时不开放公共问答；
- 测试结束立即恢复关闭状态并核对 D1 结算。
