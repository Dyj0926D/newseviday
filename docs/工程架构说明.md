# NewsEviday 工程架构说明

| 项目 | 当前基线 |
|---|---|
| 架构版本 | v0.3 |
| 日期 | 2026-08-01 |
| 状态 | P2 工程骨架完成，Cloudflare 主站已发布，EdgeOne Makers 备用站配置完成 |
| 仓库形态 | npm workspaces 单仓 + 独立 Python 项目 |

## 1. 架构目标

工程骨架优先解决四件事：

1. 页面、在线 API、离线内容管道职责分开；
2. AI 能力可以整体关闭，静态网站继续可用；
3. 换电脑后通过版本文件和锁文件重建；
4. 前端和 Worker 共用接口契约，降低字段漂移。

## 2. 模块职责

| 模块 | 路径 | 职责 | 当前状态 |
|---|---|---|---|
| Vue Web | `apps/web` | 页面、路由、响应式布局、静态快照读取 | 骨架可运行 |
| Worker 主站 | `wrangler.jsonc` + `apps/worker` | 同源托管 Vue Static Assets、状态 API、密钥隔离、未来流式 RAG | 本地 dry-run 可验证 |
| API 回滚部署 | `apps/worker/wrangler.jsonc` | 必要时将 API 独立部署，保留回滚能力 | 已发布骨架 |
| EdgeOne Makers | `edgeone.json` | 构建 Vue 静态备用站、SPA 回退和安全响应头 | 待首次云端部署 |
| 共享契约 | `packages/contracts` | API 路径和 TypeScript 响应类型 | 可用 |
| Design Tokens | `design/tokens` | CSS 与 JSON 视觉令牌 | 已作为 workspace 接入 |
| Python Pipeline | `pipeline` | 采集、清洗、去重、筛选、快照、Eval | CLI 和配置校验可用 |
| 运行配置 | `config` | 模式、开关、额度、主题、来源 | 成本安全默认值 |

## 3. 本地端口

| 服务 | 地址 | 用途 |
|---|---|---|
| Vue/Vite | `http://127.0.0.1:5173` | 页面开发 |
| Worker | `http://127.0.0.1:8787` | API 开发 |
| Vite Proxy | `/api/*` | 将前端请求转发到 Worker |

生产环境使用 Cloudflare Workers Static Assets 同源承载前端和 `/api/*`。根目录 `wrangler.jsonc` 将静态资源指向 `apps/web/dist`，SPA 未命中路径返回 `index.html`，只有 `/api/*` 进入 Worker 脚本。仓库不携带 Pages `_redirects`，避免与 Workers SPA 路由形成循环。

EdgeOne Pages 已更名为 EdgeOne Makers。根目录 `edgeone.json` 固定 Node 24.11.0、`npm ci`、Vue 输出目录、SPA 回退和基础安全头。备用站以静态只读为默认能力；后续若访问 Cloudflare API，必须通过 `ALLOWED_ORIGINS` 精确加入实际备用站来源。无自定义域名时，大陆加速区预览链接只有 3 小时有效，因此该部署目前用于备用验证，不承担永久公开入口。

## 4. 安全基线

- Vue 构建不读取 DeepSeek Key；
- Worker Secret 与本地 `.dev.vars` 保存模型密钥；
- 来源、模型和付费能力默认关闭；
- Worker 默认 CORS 白名单；
- Worker 响应包含 `nosniff`、Referrer Policy 和 Permissions Policy；
- Workers Static Assets 读取 `_headers`，设置 CSP、frame 限制和权限策略；
- 未知接口返回 404，非 GET 请求返回 405；
- CI 只需要只读仓库权限；
- 示例配置不包含真实账号、Token 或公司数据。

## 5. 成本控制

归档模式是仓库默认状态。前端请求不到 Worker 时自动保留静态页面；Worker 未配置 Key 时返回 `static-only`；Python `run` 只允许 `--dry-run`，真实执行入口会在内容管道完成并加入预算门槛后开放。

## 6. 可迁移性

| 对象 | 固定方式 |
|---|---|
| Node | `.node-version`、`.nvmrc`、`package-lock.json` |
| Python | `.python-version`、`pipeline/.python-version`、`pipeline/uv.lock` |
| npm 依赖 | npm workspaces + lockfile |
| Python 依赖 | `pyproject.toml` + uv lockfile |
| 接口 | `@newseviday/contracts` |
| 视觉 | `@newseviday/design-tokens` |
| 本地配置 | `.env.example`、`.dev.vars.example` |
| 自动验证 | `.github/workflows/ci.yml` |
| Cloudflare 生产部署 | 根目录 `wrangler.jsonc` + Workers Builds |
| EdgeOne 备用部署 | 根目录 `edgeone.json` + Makers Git 集成 |
