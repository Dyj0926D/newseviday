# NewsEviday 网址优化评估

## 1. 当前地址

`https://newseviday.dyjnewseviday-worker.workers.dev`

Cloudflare Workers 免费地址格式固定为：

`<Worker 名称>.<账号子域名>.workers.dev`

当前 Worker 名称是 `newseviday`，账号子域名是 `dyjnewseviday-worker`。

## 2. 零成本方案

### 方案 A：缩短 Cloudflare 账号子域名

建议尝试把账号子域名改为 `eviday`，目标地址为：

`https://newseviday.eviday.workers.dev`

优点：

- 免费。
- 不改变 Worker 服务名和同源 API 架构。
- 不需要新增 Pages 项目。
- 后续 Git 自动部署可以继续沿用。

限制：

- `workers.dev` 前仍必须保留 Worker 名称和账号子域名两级结构。
- `eviday` 是否可用，需要在 Cloudflare Dashboard 中实际检查。
- 修改账号子域名会影响该账号下全部 Worker 的免费地址。
- 地址变更后必须同步 Turnstile hostname 白名单、`TURNSTILE_HOSTNAMES`、文档和公开链接。
- 不能解决中国大陆直连问题。

### 方案 B：Cloudflare Pages 免费地址

理论地址可以是 `newseviday.pages.dev`。

不推荐作为当前主站。它需要把静态前端和 Worker API 分开部署，引入跨域、Turnstile hostname、CSP 和双发布流程。它同样不能承诺中国大陆稳定直连。

### 方案 C：第三方免费子域名

部分社区提供免费子域名，但通常需要人工审核、公开仓库或遵守额外规则。稳定性、品牌归属和回收风险不可控，不建议用于简历主链接。

## 3. `newseviday.edv` 是否可用

不可用。IANA 根域数据库没有 `.edv` 顶级域名。

如果想使用 `newseviday.dev`，需要向域名注册商购买 `.dev` 域名，并确认名称未被注册。Cloudflare Custom Domain 也要求域名属于当前用户，不提供免费的独立顶级域名。

## 4. 中国大陆直连边界

- 当前 Cloudflare `workers.dev` 在实测大陆网络中不可访问，VPN 后正常。
- EdgeOne Makers 临时预览链接已过期，不能作为永久入口。
- EdgeOne 使用中国大陆或全球含大陆加速区时，需要已备案的自定义域名。
- 在“不购买域名、不备案”的约束下，无法同时获得永久短网址和稳定大陆直连。

## 5. 建议

近期采用两步策略：

1. 免费缩短账号子域名，优先尝试 `eviday`，形成 `newseviday.eviday.workers.dev`。
2. 简历中同时准备 60-90 秒产品录屏，说明大陆直连属于部署约束，网站通过 VPN 可访问。

后续进入正式求职期，如果希望大陆用户直接访问，再购买一个简短域名并完成 ICP 备案。该事项继续保留在待办，不进入当前免费 MVP。
