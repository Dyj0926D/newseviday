# NewsEviday 产品说明

## 一句话介绍

NewsEviday 是一个面向产品经理、AI 产品经理和数据产品从业者的证据型技术情报站，帮助用户发现海内外动态、快速理解脉络，并沿着原始来源继续核验。

## 用户问题

技术信息分散在公司博客、研究论文、开源社区和产品公告中。海外一手资料通常存在语言门槛，普通聚合产品又容易把“标题罗列”当作信息整理。用户仍需要重复完成筛选、翻译、判断相关性和核验来源。

## 产品闭环

```text
发现信息 → 理解变化 → 按关注方向筛选 → 追问证据 → 回到来源核验
```

| 环节 | 产品能力 | 用户得到的结果 |
| --- | --- | --- |
| 发现 | 海内外官方来源、双语信息流、主题筛选 | 更快找到与工作相关的变化 |
| 理解 | 中文摘要、关键结论、为什么重要 | 降低跨语言阅读成本 |
| 定制 | 可选画像、主题权重、本地导入导出 | 形成个人关注方向 |
| 追问 | 有限步骤 Agentic RAG、文章内追问、证据不足拒答 | 得到带来源的回答 |
| 核验 | 原文链接、证据摘录、更新时间 | 可以自行判断结论是否可靠 |

## MVP 范围

- 画像是可选能力；未创建画像时使用通用主题排序；
- 原始输入和画像默认保存在浏览器本地，不建立账号体系；
- 内容刷新由人工触发，发布前需要经过规则校验和代码评审；
- AI 摘要、画像增强、RAG 和趋势简报使用独立开关；
- AI 停用时，前端继续展示最近一次通过校验的静态快照。
- “最新情报”默认展示近 30 天中文内容并按发布时间倒序；“不限时间”用于查阅更早内容和待整理原文；
- 公共趋势简报按周更新，每个趋势至少关联两个来源，生成失败时保留上一版；

## 产品亮点

1. 海内外信息采用同一套证据结构，海外内容保留原文链接和原始发布时间。
2. 推荐理由与用户关注方向关联，减少“系统为什么推荐这条”的黑盒感。
3. 生成能力受质量、成本和安全 Gate 控制，可以暂停而不影响历史内容浏览。
4. 产品介绍页同时公开产品逻辑、技术架构、RAG 过程和评测边界。

## 公开能力边界

- 当前为小规模受控生产快照；评测集仍在人工复核，在线 RAG 尚未开放；
- 画像只代表用户主动输入的职业和兴趣，不推断敏感属性；
- AI 摘要可能出现遗漏，重要判断应以原始来源为准；
- 已实现固定上限的 `bounded_v1` Agentic RAG；在线问答仍需完成人工黄金集和引用质量 Gate 后开放；
- 大陆网络连通性受免费托管域名影响，当前不承诺所有网络环境均可直接访问。
