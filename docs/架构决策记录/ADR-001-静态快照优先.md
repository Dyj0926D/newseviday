# ADR-001：静态快照优先

- 状态：已采纳
- 日期：2026-08-01

## 背景

项目需要长期低成本运行，当前受控试运行硬上限为 10 元；采集和 AI 必须能够随时暂停。Cloudflare 在中国大陆的可达性也需要备用方案。

## 决策

内容以版本化 JSON 快照为发布边界。Vue 优先请求 Worker 状态；Worker 不可用时读取同站 `/data/current.json`。Cloudflare 和 EdgeOne 共用数据格式。

## 结果

- AI、采集或 API 暂停时，历史内容和产品页面仍可展示；
- 发布可回滚到上一快照；
- 动态个性化和实时问答不能仅靠静态站完成，保留 Worker 路径；
- 快照体积增长后再评估分页与对象存储，MVP 不提前引入。
