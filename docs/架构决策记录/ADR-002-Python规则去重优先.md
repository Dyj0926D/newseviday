# ADR-002：Python 规则去重优先

- 状态：已采纳
- 日期：2026-08-01

## 背景

同一新闻可能被多个来源转载或标题轻微改写。如果每条内容都调用大模型判断重复，费用、时延和不可复现性都偏高。

## 决策

MVP 采用两级确定性去重：

1. 规范化 URL 与内容 SHA-256 做精确去重；
2. 字符三元组倒排缩小候选集，再用 `SequenceMatcher` 做模糊相似判断；
3. 单批最多 500 条，超过即失败并要求分批；
4. 语义 Embedding 去重只进入 Eval，不默认用于生产。

## 结果

- 运行免费、可测试、可解释；
- 多语言语义改写可能漏判；
- 后续用人工标注重复集评估 precision/recall，规则效果不足时再引入向量候选召回；
- 模型只处理已经去重和筛选后的少量内容。
