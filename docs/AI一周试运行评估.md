# NewsEviday AI 一周试运行评估

## 1. 结论

当前不建议一次性开启全部 AI 开关。可以先做一周受控试运行，但必须限定为画像增强、少量文章整理和指定问题的证据问答。动态趋势简报暂不进入试运行。

主要原因：

- 在线画像增强已经具备 D1、Turnstile、幂等和预算保护。
- 证据问答已经能运行，但无答案识别当前为 50%，低于 80% Gate。
- 当前在线检索是文章级基线，生产级分块检索和 Vectorize 尚未验收。
- 文章 AI 整理已有手动 Workflow，但 GitHub Actions 尚未配置 DeepSeek Secret 和 Variables。
- 动态趋势简报只有数据结构、页面和开关，没有完整的模型生成任务。
- 当前没有定时采集任务，一周试运行仍需手动触发内容更新。

## 2. 能力成熟度

| 能力 | 代码状态 | 保护状态 | 试运行建议 |
| --- | --- | --- | --- |
| 画像语义增强 | 已实现 | D1、Turnstile、预算保护已完成 | 可以第一批开启 |
| 文章翻译、摘要和标签 | 已实现 | 哈希缓存已完成，批处理缺少单次调用上限 | 增加批次上限后小批量运行 |
| 证据问答 | Demo 基线已实现 | 在线保护已完成 | 仅指定测试问题，不公开宣传为稳定能力 |
| 个性化推荐 | 本地规则已实现 | 不产生模型费用 | 保持开启 |
| 动态趋势简报 | 未完成生成链路 | 只有开关和静态页面 | 暂不开启 |
| 自动日更 | 手动 Workflow 已实现 | 默认不调用模型 | 一周试运行继续手动触发 |

## 3. 试运行前置条件

1. 恢复本机 Cloudflare Wrangler 登录，只查看 Secret 名称和 D1 状态。
2. 在 GitHub Actions 配置 `DEEPSEEK_API_KEY`，并配置模型、Base URL 和非思考模式 Variables。
3. 为批量文章整理增加 `max-model-calls`，试运行单次最多 5-10 篇。
4. 把试运行额度调低为单 IP 2 次/日、全站 5 次/日、并发 1。
5. 试运行软预算设为 5 元、硬上限设为 10 元。
6. 先完成 1 次画像调用和 1 次已知答案问答，核对 D1 Token 与费用记录。
7. 网址如需缩短，先完成 hostname 和 Turnstile 白名单迁移，再开启 AI。

## 4. 建议日程

| 日期 | 范围 | 目标 |
| --- | --- | --- |
| D0 | 配置与烟雾测试 | 验证 Key、模型、费用台账、Turnstile 和回滚 |
| D1-D2 | 画像增强 | 记录结构化成功率、延迟、错误和费用 |
| D3 | 文章整理 | 手动整理 5-10 篇，检查术语和事实边界 |
| D4-D6 | 指定问题 RAG | 10 个有答案问题加 5 个无答案问题，不向普通访客开放宣传 |
| D7 | 复盘与关闭 | 汇总费用、质量和失败案例，恢复归档模式 |

## 5. 成本估算

当前使用 `deepseek-v4-pro` 非思考模式，按 2026-08-02 官方缓存未命中输入价 3 元/百万 Token、输出价 6 元/百万 Token 估算。

- 在线生成全站限制 5 次/日时，按每次 0.10 元保守预留计算，一周最多预留 3.5 元。
- 文章整理 10 篇按每篇不超过约 0.01 元的工程估算，约 0.10 元级别。
- 实际费用预计明显低于 5 元。
- 试运行硬上限建议设为 10 元，触发后立即停止。

以上是预算控制估算，不是供应商账单承诺。最终以 DeepSeek Usage 和 D1 结算记录为准。

## 6. 成功标准

- 一周模型费用不超过 5 元。
- Secret 和问题正文不进入公开日志。
- 画像结构化成功率不低于 90%。
- 文章整理 Schema 成功率不低于 90%，术语一致性不低于 95%。
- 10 个有答案问题全部带可点击引用。
- 5 个无答案问题至少 4 个正确拒答。
- 模型请求错误率低于 10%。
- P95 响应时间不超过 Worker 20 秒超时上限。

## 7. 立即停止条件

- 出现无依据事实或引用无法支持结论。
- D1 额度、预算或 Turnstile 任一保护失效。
- 单日费用异常增长或总费用达到 5 元提醒线。
- 模型错误率达到 20%。
- 发现 Secret、原始 IP 或问题正文进入日志。

## 8. 一周后决策

- 质量和费用通过：画像增强保持小流量，RAG 继续扩大人工测试集。
- 画像通过、RAG 不通过：只开放画像，问答恢复关闭。
- 费用或稳定性不通过：全部恢复归档模式，保留静态快照。
- 趋势简报继续保持静态，等待独立生成链路与 Eval 完成。
