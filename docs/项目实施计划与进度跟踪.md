## 1. 状态定义

| 状态   | 含义                       |
| ------ | -------------------------- |
| 未开始 | 尚未进入实施               |
| 进行中 | 当前正在处理               |
| 待确认 | 已有产物，需要用户确认     |
| 阻塞   | 存在明确外部依赖或权限问题 |
| 已完成 | 产物已生成并通过本阶段验收 |
| 已取消 | 明确移出当前范围           |

更新规则：

1. 每次只保留一个主要“进行中”阶段。
2. 完成任务时记录产物路径和验证结果。
3. 出现阻塞时记录阻塞原因、影响和解除条件。
4. PRD 发生变化时先更新 `prd/CHANGELOG.md`。
5. 功能完成不等于阶段完成，阶段 Gate 全部通过后才能进入下一阶段。
6. 本文档在后续 Codex 开发任务中持续更新，不依赖当前设备的临时记录。

## 2. 实施策略

### 2.1 核心原则

- 先完成可访问、可浏览的静态产品，再接动态 AI。
- Python 负责采集、清洗、去重、规则筛选、快照和 Eval。
- Cloudflare Worker 负责在线 API、限流、密钥和流式问答。
- DeepSeek 只处理翻译摘要、画像增强、RAG 回答和趋势简报。
- 所有高成本能力先有开关、缓存和预算，再开放。
- 每一阶段都交付可演示产物，避免最后一次性集成。

### 2.2 核心版与增强版

核心版必须完成：

- 8–10 个稳定国内外来源；
- Python 内容管道；
- 首页、文章详情、产品介绍页；
- 可选画像与本地推荐；
- chunk dense RAG；
- 30 题黄金测试集；
- 归档/预热/面试模式；
- Cloudflare 主站和 EdgeOne Makers 静态备用站。

增强版根据进度执行：

- 可视化 `/admin`；
- 更多来源；
- hybrid/rerank 离线对比；
- Agentic RAG 离线实验；
- 趋势简报独立深度 Eval。
