## 2. 实施策略

### 2.1 核心原则

- 先完成可访问、可浏览的静态产品，再接动态 AI。
- Python 负责采集、清洗、去重、规则筛选、快照和 Eval。
- Cloudflare Worker 负责在线 API、限流、密钥和流式问答。
- DeepSeek 只处理翻译摘要、画像增强、RAG 回答和趋势简报。
- 所有高成本能力先有开关、缓存和预算，再开放。
- 每一阶段都交付可演示产物，避免最后一次性集成。

### 2.2 核心版与增强版

核心版必须完成：

- 6-8 个稳定国内外来源；
- Python 内容管道；
- 首页、文章详情、产品介绍页；
- 可选画像与本地推荐；
- chunk dense RAG；
- 30 题黄金测试集；
- 归档/预热/面试模式；
- Cloudflare 主站和 EdgeOne Makers 静态备用站。

增强版根据进度执行：

- 可视化 `/admin`；
- 更多来源；
- hybrid/rerank 离线对比；
- Agentic RAG 离线实验；
- 趋势简报独立深度 Eval。
