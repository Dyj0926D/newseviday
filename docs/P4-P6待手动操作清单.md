# P4–P6 待手动操作清单

本清单只记录必须由项目所有者确认、授权或在外部控制台执行的事项。代码默认保持归档模式；不完成这些步骤，网站仍可展示历史快照、产品介绍和 Demo Eval，不会产生模型费用。

## 1. 发布真实内容前

- 在 GitHub Actions 手动运行 `Manual content refresh`，首次保持 `allow_model=false`、`open_pull_request=false`。
- 下载运行产物，抽查来源、标题、正文片段、主题命中和重复项。
- 将近重复标注集扩充到至少 100 对，并完成人工复核；当前 24 对仅是工程草稿。
- 复核各来源的使用条款。公开快照优先保存标题、短摘要、必要证据片段和原文链接。
- 确认后再次手动运行，并按需启用 `open_pull_request=true`；合并前检查快照 diff。

## 2. 启用 DeepSeek 前

- 在 GitHub 仓库 Secret 中配置 `DEEPSEEK_API_KEY`，在 Repository Variables 中配置当期准确的 `DEEPSEEK_MODEL` 和 `DEEPSEEK_BASE_URL`。
- 在 Cloudflare Worker Secret 中确认 `DEEPSEEK_API_KEY`、`TRACE_HASH_SECRET`、`IP_HASH_SECRET` 已配置；两个哈希 Secret 使用不同随机值。
- 只对一篇文章执行一次最小摘要烟雾测试，核对 JSON Schema、术语一致性、Token 和估算费用。
- 画像增强只在面试演示期间短时开启。检查“预览 → 应用 → 用户保存”流程，不把画像输入写入日志。
- 完成 P7 的持久 IP 限流和预算台账前，不公开开启 `AI_ENABLED` 与 `RAG_ENABLED`。

## 3. 接入 BGE-M3 与 Cloudflare Vectorize

当前仓库已经能生成版本化 chunk、OpenAI-compatible BGE embedding 和 Vectorize NDJSON，但没有替你创建外部资源。

1. 在所选 Embedding 服务控制台确认 BGE-M3 的准确模型 ID、向量维度、价格和 API 地址。
2. 使用一次小样本调用验证返回维度，再把维度写入创建命令；不要依据文档示例盲填。
3. 在 Cloudflare 创建 Vectorize 索引并把 binding 加入 `wrangler.jsonc`。
4. 运行 `build-index --provider openai --allow-embedding-network` 生成向量，导入 NDJSON。
5. 对比本地 hashing baseline 与 BGE-M3 的 30 题结果；只有生产黄金集通过 Gate 后才切换公开检索。

示意命令中的维度必须替换为实测值：

```powershell
npx wrangler vectorize create newseviday-chunks --dimensions=<实测维度> --metric=cosine
python -m uv run --project pipeline newseviday-pipeline build-index `
  <snapshot.json> --provider openai --dimensions <实测维度> `
  --allow-embedding-network --vectorize-output data/runtime/rag/vectorize.ndjson
npx wrangler vectorize insert newseviday-chunks --file=data/runtime/rag/vectorize.ndjson
```

## 4. 黄金集与生产 Gate

- 当前 `rag-gold-demo-v1` 有 30 题，状态为 `engineering_draft_pending_human_review`。
- 逐题复核问题是否自然、预期文章是否完整、无答案题是否真的无答案。
- 用真实生产快照另建生产数据集，不要把 Demo 题直接改名为生产集。
- 补做生成回答的引用覆盖率、Faithfulness、严重编造和无答案识别人工评测。
- 生产 Gate 达标后，才允许把 Eval `gate` 标记为 `pass`。

## 5. 当前明确挂起项

| 项目 | 挂起原因 | 不执行的影响 |
|---|---|---|
| 真实 DeepSeek 调用 | 会产生费用，需要用户明确选择模型与时间窗口 | 摘要和画像继续使用手动/历史内容 |
| 定时内容更新 | 用户要求可暂停；当前工作流仅手动触发 | 网站继续展示上一版快照 |
| Vectorize 创建与绑定 | 需要 Cloudflare 外部资源操作和实测维度 | Worker 使用小语料本地 dense 基线，公开 RAG 保持关闭 |
| 去重 100 对人工标注 | 需要人工语义判断 | P4 数据 Gate 不正式签字 |
| RAG 30 题人工复核 | 需要产品判断和答案证据核对 | Eval 结论保持 `observe` |
| 公网问答开关 | P7 持久限流与预算台账尚未完成 | 避免匿名滥用和意外费用 |
