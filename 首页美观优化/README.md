# NewsEviday 首页美观优化

## 当前状态

状态：首页视觉升级已实现并通过回归；Logo 候选方向待用户选择。

本子项目只负责首页首屏、首屏到信息流之间的视觉过渡，以及与首屏直接相关的响应式和性能优化。现有信息架构、路由、筛选、推荐、情报卡片、数据读取和 API 逻辑保持不变。

## 交付顺序

1. 用户已确认“深空信号场 + 少量轨道线”。
2. 实现 Vue 首屏、公开生态带、深浅色过渡和轻量交互。
3. 完成六档视口、减少动态模式、性能和可访问性回归。
4. 生成 Logo 候选方向，用户确认后再接入生产 SVG 与 favicon。
5. 更新活动视觉基准并保留最终实现截图。

## 实施结果

- Vue 首页已接入深空首屏、原生 Canvas 信号粒子、指针响应和点击波纹。
- 首屏离开视口或页面进入后台后暂停动画；减少动态模式使用静态画面。
- 桌面最多 72 个粒子，移动端最多 28 个，设备像素比上限 1.5。
- 公开生态 SVG 全部本地打包，页面无新增业务接口和第三方图标请求。
- 16 项前端单元测试、18 项浏览器流程测试、六档宽度回归、安全扫描和 Cloudflare dry-run 通过。

## 当前确认点

已确认采用“深空信号场 + 少量轨道线”：深紫蓝首屏、稀疏信号粒子、柔和交互波纹、公开生态 Logo 带和深色到浅色情报流的渐变。预览图用于确认方向和氛围，不作为逐像素实现稿；图中低优先级正文以真实 Vue 页面文案为准。

## 边界

- 不修改 `/`、`/product` 等路由。
- 不修改内容快照、推荐算法、RAG、AI 或 Worker API。
- 不引入 Three.js 或大型 3D 运行时。
- 不在运行时从第三方 CDN 拉取品牌图标。
- 用户选定 Logo 方向前不替换现有站点标识。
