# NewsEviday 首页美观优化

## 当前状态

状态：首张 PC 效果预览待确认，尚未修改首页视觉代码。

本子项目只负责首页首屏、首屏到信息流之间的视觉过渡，以及与首屏直接相关的响应式和性能优化。现有信息架构、路由、筛选、推荐、情报卡片、数据读取和 API 逻辑保持不变。

## 交付顺序

1. 用户确认视觉方向。
2. 生成 1440px PC 和 390px 手机视觉稿。
3. 确认视觉稿后实现 Vue 组件和动效。
4. 完成六档视口、减少动态模式、性能和可访问性回归。
5. 更新活动视觉基准并归档未采用方案。

## 当前确认点

首张预览采用“深空信号场 + 少量轨道线”：深紫蓝首屏、稀疏信号粒子、柔和交互波纹、公开生态 Logo 带和深色到浅色情报流的渐变。该图片用于确认方向和氛围，不作为逐像素实现稿；图中低优先级正文仍以真实 Vue 页面文案为准。

## 边界

- 不修改 `/`、`/product` 等路由。
- 不修改内容快照、推荐算法、RAG、AI 或 Worker API。
- 不引入 Three.js 或大型 3D 运行时。
- 不在运行时从第三方 CDN 拉取品牌图标。
- 未确认前不替换现有首页。
